# Microcontroller Code

## Subsystem Overview

The microcontroller controls a linear actuator through an H-bridge motor driver for the automated laundry folding device.

## Hardware Verification

The code is designed to:

- Extend the linear actuator.
- Retract the linear actuator.
- Change actuator direction based on a digital input.
- Control a status LED.

Physical hardware verification is pending.
